Privacy Policy

Last updated: October 11, 2026

This policy covers Delta Lap Uploader, an internal tool used by the Delta Lap channel.

What the tool does

The tool uploads videos produced by Delta Lap to the Delta Lap YouTube channel, using the YouTube Data API. It is used only by the channel owner. It has no public sign-up and no other users.

Data we access

The tool requests one permission: uploading videos to the YouTube channel the owner signs in with (youtube.upload). It does not read, collect or store any other Google account data, and it does not access any data of viewers or other users.

Storage

The sign-in token is stored only on the channel owner's own computer. It is never sent to any server other than Google's. No data is sold, shared or used for advertising.

Google API Services

The tool uses YouTube API Services. See the YouTube Terms of Service and the Google Privacy Policy. Access can be revoked at any time at myaccount.google.com/permissions.

Contact

Questions about this policy: open an issue at github.com/deltalapdata/deltalapdata.github.io.
