Privacy Policy

Last updated: October 11, 2026

This policy covers Delta Lap Uploader, an internal tool used by the Delta Lap channel.

YouTube API Services

Delta Lap Uploader uses YouTube API Services. By using it, you agree to be bound by the YouTube Terms of Service. Google's handling of data is described in the Google Privacy Policy.

What the tool does

The tool uploads videos produced by Delta Lap to the Delta Lap YouTube channel, using the YouTube Data API (videos.insert). It is used only by the channel owner. It has no public sign-up and no other users.

Data we access

The tool requests one permission: uploading videos to the YouTube channel the owner signs in with (youtube.upload). It does not read, collect or store any other Google account or YouTube data, and it does not access any data of viewers or other users.

Storage and sharing

The only data stored is the OAuth sign-in token, kept in a local file on the channel owner's own computer. It is sent only to Google's servers. No data is sold, shared with third parties or used for advertising. The tool uses no cookies or tracking.

Data deletion and revoking access

Access can be revoked at any time on the Google security settings page: myaccount.google.com/permissions. Deleting the local token file removes all stored data. When access is revoked, the token stops working and is deleted the next time the tool runs.

Contact

Questions about this policy: open an issue at github.com/deltalapdata/deltalapdata.github.io.
